# ngc-icebreaker-bingo
A Typst template for Icebreaker Bingo for our NGC social events

## Compiling the pdf
The pdf will be compiled by GitHub Actions with every push you make to the repository. 
You can then download the pdf as an 'Artifact' if you [click on the latest workflow](https://github.com/next-generation-cartographers/ngc-icebreaker-bingo/actions).

To compile the pdf locally, first install the [Typst compiler](https://typst.app/open-source/).

## Print
The template is set up in A5 format. Margins get most even if paper is cut in A5 before and then the bingo is printed as A5 (as opposed to two A5 pages on A4).
